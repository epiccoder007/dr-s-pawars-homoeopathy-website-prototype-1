## Pages
Home, About, Dr. Sanjay W. Pawar, Dr. Sushant S. Pawar, Treatments, Patient Success Stories, Online Consultation, Clinics, FAQ, Contact.

## Important before production
1. Replace `YOUR-DOMAIN.com` in robots.txt and sitemap.xml.
2. Connect the appointment forms to a secure backend/form provider.
3. Configure Google Analytics and Google Search Console.
4. Add verified Google Business Profile map/embed URLs if desired.
5. Add real doctor photographs if available.
6. Review all medical/advertising claims for applicable Indian professional and advertising rules. Testimonials are presented as individual experiences and not guarantees.
7. Google Meet links should be generated/confirmed by the clinic workflow; this static version provides the request interface.
